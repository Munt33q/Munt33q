## ⚡ Featured Project

### [EEG Quality Inspector ↗](https://github.com/Munt33q/eeg-quality-inspector)

An interactive application for exploring EEG recordings and inspecting
potential signal-quality issues.

**CSV & EDF support · Interactive waveforms · Frequency analysis · Offline reports**

- Explicit signal units and configurable quality indicators.
- Built-in synthetic demonstration.
- 60 automated tests reported at initial release.
- Local processing without external API services.

[**Explore the repository →**](https://github.com/Munt33q/eeg-quality-inspector)
